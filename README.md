# Accompagner ses équipes dans l'intégration de l'IA

Le kit du participant de la formation Ambient IT : le support, les fiches de travail, la boîte à outils du manager, le projet fil rouge Lumen et les modèles pour construire l'assistant d'IA de votre équipe.

- **Durée** : 2 jours (14 heures), séparés par 2 semaines d'intersession
- **Public** : managers, responsables, dirigeants, sans prérequis technique

## Objectifs

1. Comprendre les fondamentaux de l'intelligence artificielle et ses implications pour les entreprises.
2. Identifier les opportunités, les limites et les enjeux éthiques, juridiques et organisationnels.
3. Adopter une posture de leadership éclairée pour piloter des projets intégrant l'IA.
4. Renforcer la confiance numérique : sécurité, confidentialité, détection des manipulations.
