# Glossaire

| Terme | Définition |
|---|---|
| **Agent** | IA qui enchaîne seule des actions pour atteindre un objectif. |
| **Apprentissage automatique** | Machine learning : apprendre à partir de données. |
| **Biais** | Écart systématique qui désavantage certains cas ou groupes. |
| **Charte IA** | Règles d'usage de l'IA partagées par une équipe. |
| **Compétence (skill)** | Procédure écrite que l'assistant suit pour une tâche. |
| **Consigne (prompt)** | Instruction donnée à une IA générative. |
| **DPO** | Délégué à la protection des données. |
| **Déployeur** | Organisation qui utilise un système d'IA dans son activité. |
| **Fichier d'instructions** | CLAUDE.md, AGENTS.md : règles relues par l'assistant. |
| **Garde-fous (guardrails)** | Mesures qui empêchent l'IA de mal faire, à cinq niveaux. |
| **Grand modèle (LLM)** | Modèle de langage, moteur des assistants. |
| **Hallucination** | Réponse fausse mais formulée avec assurance. |
| **Hypertrucage (deepfake)** | Faux contenu audio, image ou vidéo réaliste. |
| **IA fantôme (shadow AI)** | Usage de l'IA hors du cadre validé par l'entreprise. |
| **IA générative** | IA qui produit du texte, des images, du son, du code. |
| **Injection de consigne** | Prompt injection : ordres cachés dans un contenu lu. |
| **Jeton (token)** | Fragment de mot, unité de calcul d'un modèle. |
| **Mémoire (memory)** | Ce que l'assistant retient d'une conversation à l'autre. |
| **RGPD** | Règlement européen sur la protection des données. |
| **Règlement IA (AI Act)** | Règlement européen sur l'IA, fondé sur les niveaux de risque. |
| **Validation humaine** | Human-in-the-loop : une personne valide avant envoi. |
