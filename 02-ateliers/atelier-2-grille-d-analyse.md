# Atelier 2 — Analyser un projet d'IA

- **Moment** : jour 1, fin d'après-midi · **Durée** : 35 min
- **Format** : groupes de 3 ou 4, un cas par groupe (voir `03-cas-pratiques/`)
- **Livrable** : la grille d'analyse de mon usage prioritaire

## Consigne

1. **Analyser le cas** : noter chaque critère en vert, orange ou rouge, avec une phrase de justification.
2. **Transposer** : appliquer la grille à l'usage prioritaire de l'un d'entre vous (atelier 1).
3. **Décider** : pour chaque critère orange ou rouge, une action concrète avant de lancer.

## Gabarit

| Critère | Question | Cas étudié | Mon usage prioritaire | Action avant de lancer |
|---|---|---|---|---|
| Besoin | Quel problème réel ? Pour qui ? | | | |
| Données | Lesquelles ? Quelle qualité ? Quel droit d'usage ? | | | |
| Contrôle humain | Qui vérifie, décide, peut dire non ? | | | |
| Équipe | Associée, formée, écoutée ? | | | |
| Cadre | Règles, conformité, transparence, mesure ? | | | |

## Questions de débrief

1. Quel critère était le plus souvent rouge dans les cas ?
2. Et dans vos propres usages ?
3. Quelle action allez-vous engager en premier ?
4. De qui avez-vous besoin pour avancer ?
