# Atelier 3 — Lancer un projet IA en réunion d'équipe

- **Moment** : jour 2, fin de matinée · **Durée** : 45 min
- **Format** : groupes de 5 ou 6, deux tours de 10 minutes, retour à chaud de 5 minutes, débrief collectif de 15 minutes
- **Livrable** : mon plan de lancement (date de la vraie réunion, deux pratiques retenues)

## Consigne

Le manager lance, devant son équipe, l'usage prioritaire qu'il a choisi (ateliers 1 et 2). Il prépare 5 minutes avec le message en quatre temps : pourquoi, quoi, comment, et moi ? Les rôles sont distribués face cachée.

## Cartes de rôle (à imprimer et découper)

| Rôle | Ce que vous savez | Votre attitude | Ce qui vous ferait changer |
|---|---|---|---|
| **Le manager** | Vous lancez un test de 3 semaines sur un usage précis. | Vous voulez embarquer, pas imposer. | — |
| **L'enthousiaste** | Vous utilisez déjà un assistant avec votre compte personnel, y compris sur des documents internes. | Vous voulez aller plus vite et plus loin, tout de suite. | Un rôle reconnu et des règles claires. |
| **Le sceptique** | Vous avez connu deux « outils miracles » abandonnés. | Vous demandez des preuves et relevez les failles. | Qu'on vous confie la vérification des résultats. |
| **L'inquiet** | Une partie de votre poste est exactement la tâche visée. | Vous parlez peu. Vous ne direz votre crainte que si l'on vous y aide. | Une réponse honnête sur votre rôle demain. |
| **L'expert métier** | Vingt ans d'expérience, référent qualité de l'équipe. | Vous craignez une baisse de qualité et la perte du savoir-faire. | Que votre expertise serve à fixer les critères de qualité. |
| **L'observateur** | Vous avez la grille ci-dessous. | Vous ne parlez pas pendant la scène. | — |

## Grille de l'observateur

| Ce que j'observe | Oui | En partie | Non | Ce que j'ai entendu ou vu |
|---|---|---|---|---|
| Le pourquoi part d'un problème de l'équipe | | | | |
| Le périmètre et les règles sont clairs | | | | |
| Le manager dit ce qu'il ne sait pas | | | | |
| Chacun a pu s'exprimer, y compris l'inquiet | | | | |
| Les objections sont accueillies, pas contrées | | | | |
| Le « et moi ? » de chacun est traité | | | | |
| L'équipe repart avec un rôle et une date | | | | |

Retour à chaud : d'abord le manager, puis les participants, puis l'observateur. Des faits, pas des jugements.

## Corrigé : ce qui fait la différence

| Ce qui braque l'équipe | Ce qui embarque l'équipe |
|---|---|
| Commencer par l'outil et ses performances | Commencer par un irritant vécu par tous |
| Répondre à chaque objection par un contre-argument | Reformuler l'objection avant d'y répondre |
| Minimiser les craintes | Aller chercher la parole des silencieux |
| Monopoliser la parole | Confier un rôle au sceptique : vérificateur |
| Ne s'adresser qu'aux enthousiastes | Dire ce qui n'est pas négociable et ce qui l'est |
| Repartir sans date ni rôles | Fixer ensemble le prochain point |
