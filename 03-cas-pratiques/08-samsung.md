# Samsung : la fuite de données

**Type** : Incident

## Le contexte

Printemps 2023. Des ingénieurs découvrent un assistant conversationnel grand public et l'utilisent pour gagner du temps.

## Ce qui s'est passé

En quelques semaines : du code source confidentiel soumis pour correction, un compte rendu de réunion soumis pour synthèse. L'entreprise restreint ensuite fortement ces outils.

## Questions pour le groupe

1. Quel problème le projet cherchait-il à résoudre ?
2. Quel critère de la grille était le plus fragile ?
3. Quelle décision de management aurait changé l'issue ?
4. Qu'est-ce que cela vous inspire pour votre propre usage prioritaire ?

## Les leçons

- Aucune malveillance : l'envie de bien faire
- Pas de règle connue, pas d'outil alternatif
- L'interdiction est arrivée après coup
- Un cadre et un outil validé auraient suffi
