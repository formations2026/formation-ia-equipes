# Amazon : l'outil de tri de CV

**Type** : Controversé

## Le contexte

À partir de 2014, Amazon développe un outil qui note les candidatures de 1 à 5 étoiles, entraîné sur dix ans de CV reçus, très majoritairement masculins.

## Ce qui s'est passé

L'outil apprend à pénaliser des CV contenant le mot « women's ». Malgré des corrections, sa neutralité ne peut être garantie. Le projet est abandonné ; l'affaire est révélée en 2018.

## Questions pour le groupe

1. Quel problème le projet cherchait-il à résoudre ?
2. Quel critère de la grille était le plus fragile ?
3. Quelle décision de management aurait changé l'issue ?
4. Qu'est-ce que cela vous inspire pour votre propre usage prioritaire ?

## Les leçons

- Les données du passé portent les biais du passé
- Supprimer un mot ne supprime pas le biais
- Le recrutement est un usage à haut risque
- Savoir arrêter un projet est une bonne décision
