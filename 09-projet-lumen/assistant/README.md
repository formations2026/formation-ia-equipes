# Utiliser ces fichiers

Ces fichiers sont un exemple pédagogique, prêts à être adaptés.

| Outil | Comment les utiliser |
|---|---|
| Assistant avec « projets » et instructions de projet | Coller le contenu de CLAUDE.md dans les instructions du projet ; déposer les fichiers de connaissances/ comme documents du projet. |
| Outil qui lit un fichier d'instructions dans un dossier (Claude Code lit CLAUDE.md ; de nombreux outils lisent AGENTS.md) | Placer le dossier tel quel ; l'outil relit le fichier au début de chaque session. |
| Outil qui prend en charge les compétences (skills) au format SKILL.md | Ajouter les dossiers de competences/. |

Les noms, l'emplacement et la prise en charge de ces fichiers varient selon les outils et leurs versions : vérifier avec la DSI. Les garde-fous techniques (niveaux 2, 3 et 5 de garde-fous.md) ne se configurent pas dans ces fichiers mais dans l'outil lui-même.
